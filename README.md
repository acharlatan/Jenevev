# JENEVEV

A static, responsive JENEVEV nail studio concept page based on the supplied visual reference. Cloudflare Pages serves the repository root without a build step.

The celestial illustrations and nail gallery are AI-generated concept imagery, not photographs of completed client work. The visit form creates a copyable draft in the browser; it does not send a request, check availability, or make a booking. Studio contact details, availability, and social accounts have not been configured.
